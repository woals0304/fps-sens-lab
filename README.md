# FPS 감도 진단기

브라우저 안에서 짧은 시험을 진행하고, 자동 측정 결과를 바탕으로 FPS 감도 후보를 추천하는 개인용 도구입니다.
현재 베타는 오버워치 회전 기준을 기본 프로필로 사용하며, 짧은 진단과 이해하기 쉬운 결과 제공에 집중합니다.

- 게임 메모리 접근 없음
- 외부 게임 후킹 없음
- 브라우저 안에서만 동작
- `localStorage` 기반 자동 저장 / 자동 복구 지원
- 소수점 2자리 감도 정밀도 지원

## 기본 사용자 흐름

기본 흐름은 최대한 단순하게 유지합니다.

1. `감도 찾기` 화면에서 `DPI`와 `현재 게임 감도`만 입력합니다.
2. `바로 시작하기`를 누릅니다.
3. 몰입형 시험 화면에서 짧은 비교를 몇 번 진행합니다.
4. 추천 감도와 안정 범위를 확인합니다.
5. 원할 때만 `자세히 보기`에서 세부 결과를 확인합니다.

기본 목표는 2~5분 안에 추천 감도를 받는 것입니다.

## 입력은 두 가지만 받습니다

기본 입력은 아래 두 개만 받습니다.

- DPI
- 현재 게임 감도

아래 값은 기본 화면에서 직접 입력받지 않습니다.

- 최소 감도
- 최대 감도
- 시험 간격
- 시야각(FOV)

이 값들은 모두 내부 엔진이나 고급 설정에서 처리합니다.

## 현재 감도는 시작점일 뿐입니다

입력한 현재 감도를 절대 기준으로 믿지 않습니다.

내부 엔진은 아래 순서로 탐색합니다.

1. 넓은 1차 탐색
2. 낮은 쪽 / 높은 쪽 방향 판별
3. 탐색 중심 재조정
4. 좁은 비교
5. 미세 조정
6. 최종 확인

즉, 현재 감도가 많이 틀려 있어도 현재 감도 주변만 맴돌지 않도록 설계되어 있습니다.

## 시야각(FOV) 정책

FOV는 감도 체감에 영향을 줄 수 있지만, 기본 흐름을 복잡하게 만들지 않기 위해 고급 옵션으로만 제공합니다.

- 기본 화면에서는 FOV를 묻지 않습니다.
- 기본값은 오버워치 기준 가로 시야각 103(16:9)을 사용합니다.
- 렌더러에는 현재 캔버스 비율에 맞춰 세로 시야각으로 변환한 값을 전달합니다.
- 시야각을 따로 바꿔 쓰는 경우에만 `설정 > 고급 시험 설정`에서 사용자 지정 시야각을 켤 수 있습니다.
- 사용자 지정 시야각을 끄면 다시 오버워치 기준값으로 돌아갑니다.

세션에는 아래 정보가 함께 저장됩니다.

- 기본 시야각 사용 여부
- 사용자 지정 시야각 사용 여부
- 실제 적용된 시야각 값

결과 화면에서는 FOV를 크게 보여 주지 않고, 세부 정보 안에서만 확인할 수 있습니다.

## 시험 화면

시험 중에는 화면을 크게 쓰고, 방해되는 UI를 최대한 숨깁니다.

시험 중 표시되는 정보:

- 현재 감도
- 현재 단계
- 남은 비교 횟수
- 예상 남은 시간
- 시험 나가기

시험 시작 전에는 작은 안내 카드가 보이지만, 시험이 시작되면 중앙 안내 카드는 숨기고 얇은 HUD만 남깁니다.
그래프, 긴 설명, 세부 점수표는 시험 중에는 보이지 않습니다.

## 포인터 잠금 안정화

시험 중 마우스 커서가 화면 밖으로 튀는 문제를 줄이기 위해 아래 처리를 넣었습니다.

- 같은 시험 세션 동안 같은 캔버스와 같은 카메라 컨트롤러를 유지
- `pointerlockchange`, `pointerlockerror` 이벤트 처리
- `blur`, `visibilitychange` 발생 시 시험 즉시 일시정지
- 포인터 잠금이 풀린 상태에서는 입력 기록 중지
- 잠금이 풀리면 `클릭해서 다시 시작` 안내 표시
- 중단 안내에서 같은 단계를 다시 시작하거나 시험 화면을 바로 나갈 수 있음
- 시험 캔버스에 `cursor: none`, `user-select: none`, `touch-action: none` 적용

## 시험 길이 상한과 조기 종료

기본 모드는 너무 길어지지 않도록 상한이 있습니다.

- 빠른 시작 모드 전체 묶음 수 상한 적용
- 재중심화는 최대 1회
- 최종 확인은 짧은 확인 규약 사용
- 경향이 충분히 분명하면 조기 종료

즉, 더 정확한 탐색보다 `짧고 예측 가능한 완료`를 우선합니다.

## 시험 규약

모든 감도는 같은 조건에서 시험합니다.

### 기본 규약

- 순간 조준 시험: 표적 20개
- 추적 조준 시험: 15초
- 회전 반응 시험: 10회

### 빠른 시작 규약

- 순간 조준 시험: 표적 8개
- 추적 조준 시험: 6초
- 회전 반응 시험: 4회

### 최종 확인 규약

- 순간 조준 시험: 표적 6개
- 추적 조준 시험: 4초
- 회전 반응 시험: 3회

## 감도 정밀도

감도는 표시만 2자리가 아니라 실제 추천 로직도 소수점 2자리 기준으로 계산합니다.

- 초기 탐색은 0.05 또는 0.10 간격을 사용할 수 있습니다.
- 미세 조정은 0.01 또는 0.02 간격까지 내려갑니다.
- 최종 확인은 추천 감도 주변을 더 촘촘하게 다시 비교합니다.
- 최종 추천 감도, 안정 범위, 상하 대안 감도도 2자리 기준으로 확정합니다.

## 자동 측정 항목

### 순간 조준 시험

- 평균 목표 도달 시간
- 명중률
- 한 번에 맞춘 비율
- 지나친 뒤 되돌아온 횟수
- 클릭 전 흔들림 정도
- 평균 지나침 정도

### 추적 조준 시험

- 조준점과 표적 사이 평균 거리
- 표적 위에 머문 시간 비율
- 추적 끊김 횟수
- 움직임 안정성
- 평균 보정 빈도

### 회전 반응 시험

- 각도 오차
- 목표 도달 시간
- 지나침 각도
- 보정 횟수
- 회전 완료 후 안정화 시간

## 자동 저장 / 복구

모든 시험 결과는 `localStorage`에 자동 저장됩니다.

자동 저장 시점:

- 시험 하나가 끝날 때
- 단계가 바뀔 때
- 추천 감도나 최종 확인 결과가 바뀔 때

저장 항목:

- 날짜 / 시간
- DPI
- 현재 감도
- 자동 계산된 시험 범위
- 시야각 설정
- 자동 측정 지표
- 추천 감도 / 안정 범위
- 후보 통과 / 탈락 기록
- 최종 확인 결과
- 자동 생성 해석 문장

## 오버워치와 회전 거리 맞추기

- 기본 입력은 계속 `DPI`와 `현재 감도` 두 가지만 받습니다.
- 프로젝트 시험실은 기본적으로 오버워치와 같은 회전 거리 공식을 사용합니다.
- 기준 공식은 오버워치 yaw 값 `0.0066`을 바탕으로 계산합니다.
- 빠른 시작을 바로 써도 회전 거리는 같은 기준으로 적용됩니다.
- FOV는 화면이 보이는 느낌에 영향을 주지만, `cm/360` 자체를 바꾸지는 않습니다.

고급 설정과 고급 시험 화면에서는 아래 값을 확인할 수 있습니다.

- 오버워치 기준 `cm/360`
- 현재 시험실 기준 `cm/360`
- 차이 비율

확인 방법:

1. `감도 찾기`에서 기본값으로 시작하거나 `설정`으로 이동합니다.
2. `고급 시험 설정`을 열어 `회전 거리 확인` 항목을 봅니다.
3. `입력 보정 배율`이 `1.00`이고 원시 입력이 켜져 있으면 오버워치와 거의 같은 회전 거리를 목표로 합니다.
4. 결과 화면의 `세션 정보`에서도 같은 값을 다시 확인할 수 있습니다.
